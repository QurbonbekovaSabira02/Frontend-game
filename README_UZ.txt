FRONTEND CHALLENGE — ISHGA TUSHIRISH

1. index.html, style.css va script.js fayllarini bitta papkada saqlang.
2. Google hisobingizda https://script.google.com/ saytini oching va New project bosing.
3. Ochilgan Code.gs ichidagi kodni o‘chirib, ushbu papkadagi Code.gs kodini joylashtiring.
4. Save tugmasini bosing.
5. Deploy -> New deployment -> Select type (⚙) -> Web app ni tanlang.
6. Execute as: Me. Who has access: Anyone. Deploy ni bosing.
7. Google ruxsat so‘rasa, o‘z hisobingiz orqali ruxsat bering. Web app URL manzilini nusxalang.
8. script.js faylini oching va quyidagi qatorni toping:
   const GOOGLE_SCRIPT_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
   Qo‘shtirnoq ichiga nusxalangan URL manzilni qo‘ying va faylni saqlang.
9. Saytni internetga joylang (masalan, GitHub Pages yoki Netlify). Fayllarni hostingga yuklang.
10. Sinov uchun o‘zingiz testni yakunlang. Natija sarakim2224@gmail.com manziliga kelishini tekshiring.
